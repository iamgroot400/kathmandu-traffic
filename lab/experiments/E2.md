# E2 - Queue-actuated adaptive signal control vs fixed-time

- **Status:** done
- **Owner:** human
- **Tests hypothesis:** H1
- **Prediction (written BEFORE running):** If H1 holds we expect adaptive control to reduce total delay relative to fixed-time, with the paired-seed CI excluding zero. If the CI straddles zero, or if adaptive wins on some seeds and loses on others without a consistent sign, H1 is in trouble.
- **Method:** Same network/demand/routing as E1, queue-actuated hysteresis control (`adaptive_signals.py`) replacing fixed 90s cycles at the same 128 signalised nodes. 15 paired seeds, tmax=14400.
- **Metric & baselines:** Paired difference in average delay (s) vs fixed_time on identical seeds, 95% t-CI.
- **Assumptions relied on:** A1-A5, A7, A8, A10
- **Budget:** 15 seeds × ~2min = ~30 compute-min
- **Code & command:** `python scripts/compare.py` config=`adaptive` (commit history: "Add queue-actuated signal control")
- **Results:** `results/comparison.partial.csv` (config=adaptive). n=15: delay 1764±179s vs baseline 2351±165s → **−24.50% ± 7.08%, 15/15 seeds negative.**
- **Interpretation:** Matches the prediction — CI excludes zero, sign is consistent across all 15 seeds. H1 supported. Caveat: this is a queue-actuated heuristic (A8), not true max-pressure control — no turn-movement data exists to build one in this mesoscopic model, so the *size* of the effect may not transfer to a real max-pressure deployment.
