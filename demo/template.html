What this is and is not. A mesoscopic simulation (UXsim) on the real OpenStreetMap road network with a synthetic demand model, showing run 11 of 15, the run closest to the average result. Against real 2011-12 counts at 9 intersections the model carries about half the observed traffic, so read the comparison between the two maps, not the absolute speeds. Pricing here only re-routes trips; no trips are priced off the road. Map data © OpenStreetMap contributors.
