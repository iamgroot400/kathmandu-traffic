# Claim ledger

Every number in the paper, where it comes from, and how it is computed. Generated by `paper/evidence.py` from `results/clean/`; do not edit by hand.

**Source of every number below, unless the section says otherwise:** one public run on Kaggle.

- Dataset (code, network, survey inputs): https://www.kaggle.com/datasets/aashikkhatri/kathmandu-traffic-sim
- Notebook 1, `1-build-demand`: https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-1-build-demand -> demand and network inputs (od_matrix*.csv, minor_ways.txt)
- Notebook 2, `2-baseline-and-validation`: https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-2-baseline-and-validation -> sim/results/jica_sweep_summary.csv, sim/results/jica_sweep/_geh_*.csv, sim/results/tolls_jica.csv
- Notebook 3, `3a-interventions-seeds-1-8`: https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-3a-interventions-seeds-1-8 -> sim/results/jica_h1h7.partial.csv (3a: seeds 1-8, 3b: seeds 9-15)
- Notebook 4, `4a-projection-seeds-1-8`: https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-4a-projection-seeds-1-8 -> projection_seeds1-8.csv (4a) + projection_seeds9-15.csv (4b)
- Notebook 5, `5-results`: https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-5-results -> reads 2, 3a/3b, 4a/4b and prints every table below
- Notebooks 3b and 4b (seeds 9-15): https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-3b-interventions-seeds-9-15, https://www.kaggle.com/code/aashikkhatri/kathmandu-traffic-4b-projection-seeds-9-15

`tools/fetch_results.sh` downloads those outputs into `results/clean/`; the **Notebook** column names the stage that produced the file. Intervals are 95% t intervals over seeds; paired tests use the same seed in both arms, and both arms of each comparison generate the same vehicles (checked when the paper builds; H7 vs baseline removes trips by design).
